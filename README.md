
# Tic Tac Toe – Android App

## Overview
A classic two-player Tic Tac Toe game developed using MIT App Inventor. The app runs on a simple 3x3 grid where two players take turns marking their positions with X and O.

## How It Works
- Player X and Player O take turns tapping empty cells on the grid to place their mark
- The app continuously checks the board after each move to detect a winning combination
- Once a player wins, the app displays a message such as "Player X Wins!"
- If all cells are filled with no winner, the app declares a draw
- Tapping **Reset Game** clears the entire board, allowing players to start a fresh match

## Features
- 3x3 interactive grid layout
- Real-time win/draw detection
- Clear on-screen result display
- One-tap game reset functionality
- Simple, distraction-free UI

## Tech Stack
- **MIT App Inventor** (blocks-based visual programming)
